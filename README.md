# 🍰 Recipe Website - Gulab Jamun

A simple, responsive, and visually pleasing recipe webpage built using only **HTML** and **CSS**. This project showcases the traditional Indian sweet **Gulab Jamun** with structured ingredients, step-by-step instructions, and styling for a smooth user experience.

---

## 💡 Features

- Clean and minimalistic design
- Fully responsive layout
- Well-organized sections for:
  - Ingredients
  - Step-by-step cooking instructions
  - Final serving tips
- Styled using only CSS (no frameworks or JavaScript)
- Mobile-friendly

---

## 🛠️ Technologies Used

- HTML5
- CSS3
